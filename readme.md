## 📂 Available Tools

### 🔹 [IntelliChorus Recorder](IntelliChorus%20Recorder/IntelliChorus%20Recorder.lua)
> Punch-in based, multi-layer chorus recording script

- Automatic track creation with panning
- Optional folder wrapping
- Muting of previous takes
- "Count-in once" option
- Spoken feedback via screen reader — or silence mode
- Saves the project after recording (optional)

📖 [Read the PDF Guide](IntelliChorus%20Recorder/help.pdf)

---

## 📥 Install via ReaPack

1. In REAPER, open: `Extensions → ReaPack → Manage Repositories`
2. Click **Add**
3. Paste this URL:
```
https://github.com/Unique-Creators/scripts/raw/main/index.xml
```

4. Sync the package list
5. Search for `"IntelliChorus"` and install it!
